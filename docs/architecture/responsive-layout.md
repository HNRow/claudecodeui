# 响应式工作区

工作区按浏览器可用宽度适配，不绑定某个手机型号。根布局限制在视口内，文件、Git、
聊天和插件页面可在各自区域滚动，主列允许收缩，不用固定最小宽度撑开页面。

聊天记录、输入框、权限提示、排队消息与定时消息使用可用主列宽度，保留手机上的
必要内边距，不再受固定 868px 上限限制。消息气泡和图片仍保留各自的阅读尺寸。

桌面侧栏的实际宽度不超过视口的 40%，保留 220px 下限及原有 640px 存储上限。
缩窄窗口只临时压缩显示宽度，不覆盖用户偏好；扩大窗口后恢复偏好宽度。

右侧快捷设置仅在至少 1280px 的视口中允许固定占列；更窄的横屏和大屏移动设备
使用覆盖式抽屉，保留原固定偏好。关闭的抽屉通过 `hidden` 退出布局和键盘焦点范围，
不在屏幕右侧保留可操作的离屏内容。高度跟随可用容器，不强行使用 `100vh`。

相关回归测试：

```sh
npx vitest run src/shared/tests/useSidebarWidth.test.ts \
  src/modules/quick-settings-panel/tests/quickSettingsResponsive.test.tsx
```

浏览器检查应覆盖 320、390、430、768、844、1024、1440、1920px 的宽度，检查
聊天和插件容器边界、桌面大侧栏缩窄、抽屉开启/关闭、固定偏好及旋转后的恢复。
Chromium 视口模拟不等同于 iPhone Safari 真机验收；刘海、安全区域和软键盘仍需
在实际设备上确认。
